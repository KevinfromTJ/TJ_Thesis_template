# 基于 Adobe/Word PDF 的重新核对

核对日期：2026-11-11。此前将 LibreOffice 导出用于封面和声明页校准不可靠；该部分结论撤回。本轮只使用原始 Word 明确要求、原生 DOC 分节参数、用户提供的 Adobe/Word PDF 和上游已有样例。旧稿保留在 `before/`，便于追溯。

## 依据和优先级

1. `official_ref_2510/` 中的写作指南及示例文字要求。
2. 用户的 `同济大学研究生学位论文写作参考示例_adobe转.pdf`：20页，元数据为 Acrobat PDFMaker 26 Word 版 / Adobe PDF Library 26.2.15。它是本次视觉基准。
3. `upstream/TongjiThesisForCS/样例论文.pdf`：29页，确实已有完整样例，不应忽略。但该 PDF 与当前源码并非完全同步，且含旧声明文字，不能替代学校要求。
4. huang 分支继续作为代码底稿；保留先前有指南依据的边距、页眉页脚、字号、正文行距、文献及附录修正。本轮不因另一分支有 PDF 就整套替换。

[输入文件哈希与PDF元数据](sources.json)。[并排检查入口](../../compare/README.md)。原始 DOC 分节分析仍有效；LibreOffice 转换外观与从其推导的行距结论不再有效。

## 本轮改动

- **封面信息行**：撤销此前16bp行距。Adobe专业封面信息首行407.64bp，相邻行31.2bp；Word文档网格节距15.6bp也提供交叉依据。新模板采用31.2bp，日期独立固定在页底，不随可选字段减少而上移。中英文封面题目、标志和信息区域分别定位；标志直接从用户PDF提取，按指南居中，不复制Word中文封面标志的水平偏移。
- **声明表单**：撤销按字号直接乘1.4/1.5得到19.6/21bp的做法。Adobe实测约25.4/27.24bp；恢复标题、分隔线、签名与日期区域位置。声明文字仍由TeX排版，题目超出预留区域时编译报错，避免静默叠印。签名位置固定，因此短题目留下更多空白属预期。
- **章标题和一级标题**：旧版章标题低约6.48bp，章后一级标题及首行正文反而过高。修正CTeX段距与Word字体行盒之间的映射，以及紧接章标题时被CTeX吞掉的节前间距。字号保持16/15bp；不能把“单倍行距”直接等同于字号。实际CTeX skip值并非Word段落面板数字的逐项照抄。
- **页边距**：没有随视觉校准改变。仍为A4，上下25.4mm、左右31.7mm、装订线0。正文20bp、目录18bp、文献16bp保留。
- **验证入口**：加入 `tests/adobe-proof.tex` 的同内容摘录。更新旧回归脚本按页眉定位文献续页，避免标题间距变化后仍把固定物理页当成文献续页。

## 明确保留的差异与验证边界

- Word与XeLaTeX标点压缩、两端对齐和中西文间距仍不同。同内容首段存在若干行末文字不同，未用手动断行掩盖。因此不宣称逐像素一致，也不能用不同正文的分页差异判断页边距。
- 目录示例实际缩进约12/24bp，文字要求为2/4字符。保留指南的24/48bp，不按示例反向缩小。封面类型副标题标注三号16bp，但Adobe实际约18bp；继续按明确字号16bp。学校示例罗马页码与正文页码字体/字号也存在不一致，模板按文字要求统一宋体五号。
- 二、三级节标题、多行标题、公式/浮动图表周围空白未做同内容逐页校准；目前保留指南字号与相应段距设置。一级标题修正已用“章后直接接一级标题”的同内容样例验证，不能把这个结果推广成所有段落组合已完全匹配Word。
- 封面学术型、专业型位置分别配置；正式成品验证以专业硕士为主。同等学力、涉密封面及很长的字段仍需单独检查。封面保留长字段警告，不自动缩小字体塞进预留空间。
- 正式示例15页、隐名12页、书脊1页，XeLaTeX2026/Biber配套编译完成；扩展回归19页通过版心、20/18/16bp行距、目录/文献缩进、页眉页码、匿名样例和日志检查。相比旧回归增加1页是标题留白变化的结果。
